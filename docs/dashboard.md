# Обзор магазина — контракт

29.09.2026 владелец согласовал светлый дашборд в `/manager` по предложенному эскизу. Заказы/склад переезжают в `/manager/orders`; существующие команды сохраняются. CMS остаётся редактором товаров и статей. Старые ссылки с `#manager-*` переводятся на страницу операций.

Доступ: только сотрудник с правом торговых операций через существующую CMS-сессию; API no-store. До входа отдаётся оболочка без данных. Эскизные суммы и отзывы не используются.

- Периоды: сегодня,7,30 календарных дней по Москве, включая текущий неполный день. Оплаты группируются по времени первого принятого события `ar_payment_events.outcome=paid`, не по времени создания заказа. Только succeeded, согласованные paid-статусы заказа и проверенные тестовые провайдеры; повторные события/попытки не удваивают заказ. Товары и доставка отдельно, средний чек по товарам, обычные/предзаказы отдельно. Текущий магазин работает только в тестовой среде: обзор честно помечен, реальные продажи ещё не подключены. Для будущего live нужны постоянная маркировка среды заказа и поддержка реального провайдера; текущие исторические заказы не превращать в реальные переключением env.
- Очереди задач и заказов в работе — текущее состояние за всё время, независимо от периода графика. Истёкшие ожидания оплаты не считать активными. Фильтры: все/обычные/предзаказы, ждут сборки, уточнение доставки, подтверждение предзаказа, проверка оплаты. Список до50 строк, общее количество видно; переход к конкретному заказу работает и для записей старше первых100.
- Склад: недемонстрационные активные физические SKU, on_hand/reserved/free; настраиваемый общий порог низкого свободного остатка0–100. Порог и фильтры сохраняются только в браузере, денег/данных покупателей в localStorage нет. У комплектов отдельного остатка нет: доступность по составляющим.
- Готовность каталога: нет эффективного фото, упаковки SKU, подтверждённого правила совместимости; учитываются режимы inherit/replace. Для комплектов — состав и данные компонентов. Демо/архив исключены. Пустое описание и отсутствие опубликованного исполнения отмечаются отдельно. Счётчик — товары, не сумма всех проблем.
- Автообновление каждые60сек только видимой страницы, без параллельных запросов и без сброса фильтров. Сбой сохраняет прежние показатели с предупреждением и временем последнего успешного ответа;401/403 скрывает данные и возвращает вход. Пустой период показывает ноль и пояснение. Недоступный ответ не заменяется нулями.

Без новых миграций, изменений остатков, заказов или настроек платежей. Посещаемость/конверсия и прибыль отложены до подключения аналитики и данных о себестоимости. Сетевую проблему B13 по просьбе владельца не исследовать.
