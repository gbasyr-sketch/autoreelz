# Подготовка уведомления РКН

14.10.2026 владелец сообщил: уведомление об обработке персональных данных не подавал. Документ помогает собрать сведения; он не является отправленным уведомлением. Портал: https://pd.rkn.gov.ru/operators-registry/notification/. При текущей проверке портал не ответил; форму и актуальные поля проверить при подаче.

Интернет-магазин использует автоматизированную обработку данных покупателей и посетителей. Применимость уведомления и исключений определяется [ст.22 №152-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_61801/d996966e22e1320c9de1ab82d9f6be12c3d9d765/); тестовый режим не означает отсутствия обработки реальных данных. Уведомление подаётся до начала соответствующей обработки; фактическую уже наступившую дату нельзя заменять вымышленной будущей датой.

## Известные сведения

- Оператор: ИП Гурбанов Абдулбасыр Кямильевич. ИНН/ОГРНИП подтверждены ранее переданным PDF и перенесены в проект страницы контактов.
- Сайт: https://autoreelz.ru. Публичный контакт: in@autoreelz.ru.
- Цели: заключение/исполнение розничных договоров, доставка/расчёты/чеки/возвраты; кабинет и обработка обращений; работа/защита сайта; добровольная веб-аналитика после отдельного согласия. Рассылки и публикацию отзывов не включать как уже запущенные без фактического основания.
- Категории: покупатели/получатели, обратившиеся лица, посетители сайта. Состав для каждой цели сверить с [политикой и аудитом](legal-publication.md).
- Данные заказа: имя, телефон, email, адрес/ПВЗ, состав/суммы/статусы. Карточные PAN/CVC и коды подтверждения магазин не получает.
- Способы: автоматизированная обработка в магазине и обработка обращений сотрудником; сеть Интернет. ЮKassa/СДЭК/хостинг/почта/защита/копии/Метрика — по конкретным функциям и договорам.

## Что необходимо заполнить по фактам

1. Регистрационные сведения и адрес оператора из документов ИП. ПВЗ возврата MKHCH13 не подставлять как адрес регистрации автоматически.
2. Действительная дата начала обработки, основание прекращения, ответственное лицо и контакт для РКН. Не объявлять публичную почту SMTP-сервисом магазина без настройки.
3. Место нахождения баз данных граждан РФ: поставщик, страна и точный адрес размещения основной БД и копий. IP сервера и слово «Россия» не заменяют сведения провайдера. Запросить их из договора/кабинета размещения и условий хранения копий.
4. По каждой цели — категории субъектов/данных, основания, действия, способы и сроки. Не ставить «согласие» универсальным основанием для всех операций: исполнение договора/обязанности продавца и добровольная аналитика различаются.
5. Фактически выполненные организационные и технические меры: доступ, ответственные, учёт/локальные документы, защищённые соединения, резервирование, обработка запросов, удаление и инциденты. Не отмечать меры, которые пока только запланированы.
6. Проверить наличие трансграничных передач, в частности запросы браузера к OpenStreetMap и внешним плеерам. При наличии — отдельно оценить предварительное уведомление по ст.12; уведомление оператора по ст.22 его не заменяет.

Подачу и подписание владелец выполняет от имени ИП после проверки сведений. Сохранить подтверждение подачи/регистрации приватно, а в docs/status.md — только факт и дату без лишних персональных данных. После изменения целей/сервисов проверять необходимость актуализации уведомления.
