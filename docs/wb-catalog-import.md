# Первое наполнение из Wildberries

23.09.2026. Владелец предоставил две выгрузки и разрешил перенести хотя бы 30 товаров для визуальной проверки сайта. Импорт выполнен через CMS и штатный складской API нового AUTO REELZ. Исходные книги не изменялись.

## Источники и правила

- Общие характеристики от 22.09.2026, лист «Товары»: 148 артикулов, 39 групп; данные с 5 строки.
- Шаблон цен от 23.09.2026 23.32, Sheet1: 148 строк данных. Метаданные XLSX ошибочно ограничивают область A1: прочитаны фактические строки XML.
- Все 148 строк совпали по артикулу WB и артикулу продавца. Хеши файлов и номера исходных строк — artifacts/wb-catalog/import.json.
- Цена = текущая цена × (100 − текущая скидка)/100, точные десятичные рубли. Новые цены/скидки пустые. Дополнительную скидку WB/клуба, старые цены и акционные плашки не добавляли.
- На склад перенесены только «Остатки продавца». Запасы WB исключены. Три выбранных SKU получили суммарно 28 шт. через идемпотентные складские команды. Остальные 27 имеют нулевой остаток и показываются предзаказом.
- Для первой партии выбрано по одному исполнению из 30 групп: ручки КПП, отопители, уголки зеркал, рамки, консоли, воздуховоды. Наборы с неустановленным составом, смешанная группа 33 и внешние рамки номеров не вошли. WB-группа не считается автоматически одной моделью с вариантами.
- Имена, описания, артикулы, бренд и цвет взяты из источника. Тексты WB не превращены автоматически в подтверждённые правила совместимости по годам/кондиционеру. Рейтинг, налоговая ставка и видео не импортировались как отзывы, настройки чеков или плееры.
- Вес упаковки переведён из кг в г, размеры — из см в мм. Упаковка для одной штуки; для нескольких нужны отдельные правила.

## Результат

Добавлены 30 товаров, 30 SKU, 30 упаковок, 3 категории и 60 фотографий. Существующая «гранта зеленая» получила 2 фотографии по точному артикулу; её цена 1800 ₽ и текущий остаток сохранены. В публичном каталоге теперь 35 карточек, 3 страницы по 12. Ранее опубликованные товары не удалялись. Изображения загружены в Directus и отдаются с домена магазина.

Манифест с URL, ID и ценами — artifacts/wb-catalog/import.json. Исходные данные, фотографии и скрипты — private/wb-import, вне Git. Импорт одноразовый; синхронизация с WB не включена. Не запускать общий seed или повторный импорт базы.

Backup перед импортом: /srv/autoreelz2026/backups/before-wb-catalog-20260923T203959Z.dump, режим 0600; pg_restore --list проверен. Откат карточек — архивирование только ID из манифеста. Если уже появились заказы, не удалять SKU/складскую историю и не восстанавливать старую БД поверх рабочей.

Наполнение выявило обрезание вертикальных фото: подготовлена правка размера строки CSS Grid в галерее и миниатюрах. Схема БД и торговая логика не меняются. Публичная проверка будет записана в artifacts/wb-catalog/public-check.json.
