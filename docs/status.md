# Состояние AUTO REELZ

Обновлено 21.09.2026. Этапы 0 и 1 завершены: план согласован, два визуальных направления подготовлены. Ожидается выбор дизайна владельцем. Этап 2, CMS, БД, Docker, публикация и реальные операции не запускались.

## Что готово

- Независимый Git-репозиторий; исходный бриф и new-store-kit сохранены. Дополнения владельца — в [decisions.md](decisions.md).
- Девять оригинальных PDF айдентики; векторные экспорты горизонтального логотипа для светлого и графитового фона, без изменения контуров/пропорций.
- Два направления: **A — Светлая витрина** и **B — Техно**. Для каждого главная и карточка товара, desktop/mobile. Объяснения и проверки — [design-directions.md](design-directions.md).
- Общая страница сравнения: http://127.0.0.1:14321/. Запуск: `python3 prototypes/serve.py`. Сервер ограничен localhost и папкой prototypes.
- Фото заменены согласованными подписанными заглушками. Шрифты с кириллицей локальные, лицензии сохранены. Демонстрационные цены/наличие обозначены; совместимость не выдумывается.

## Подтверждено пользователем

План и предложенный объём первой версии приняты. При частичной нехватке целая строка корзины уходит в предзаказ; конкурирующие строки — в порядке добавления, результат показывается до подтверждения. Пользователь имеет GitHub-репозиторий и передаст его позже; remote пока отсутствует.

Docker использовать на этапе среды для отдельных PostgreSQL/Directus; для воспроизводимого запуска витрины также предусмотреть контейнер. Прототипы сейчас работают без Docker. Старые ресурсы не изменялись.

## Проверено

Подготовительный аудит: UI/UX Pro Max, Astro Docs, Context7, Playwright/Chrome, референсы, PDF, точная копия брифа и lockfile. Подробности — [readiness.md](readiness.md), [versions.md](versions.md).

Прототипы: четыре страницы, ширины 375/768/1024/1440, без горизонтального переполнения и ошибок JS/ресурсов. Просмотрены снимки desktop/mobile. Выбор варианта, количество, избранное, демо-корзина, проверка авто с неопределённой совместимостью, модальные окна, клавиатура и reduced motion проверены. В A исправлены пропорции медиа и миниатюры. Локальные Manrope/Oswald реально отрисовывают кириллицу в Chrome.

Сборка Astro, выбранный runtime Node 24, миграции/права CMS, торговые транзакции, внешние API и реальные показатели производительности ещё не проверены — соответствующие этапы не начаты. Прототипы не являются работающим магазином.

## Оставшиеся решения и материалы

1. **Сейчас:** выбрать A/B или назвать элементы для сочетания. MASTER.md фиксируется после выбора.
2. **До наполнения:** нужны фактические SKU/артикулы, цены/остатки, составы, годы/модификации/кондиционер, материалы, фотографии, упаковка и коробки. Данные совместимости пока не предоставлены.
3. **До реальных продаж:** эквайринг/чеки, СДЭК, реквизиты ИП, email/MAX, сервер, лицензия CMS и адрес GitHub-репозитория.
4. **До платной генерации:** модель, бюджет и входные поля. Пока имитатор по плану.

Не спрашивать повторно о домене, рознице, палитре, заглушках, частичной нехватке, фиксированных комплектах, email-коде или согласованных сроках предзаказа. Тип панели пока не подтверждён; тип отопителя исключён брифом.
