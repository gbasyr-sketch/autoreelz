# Подтверждённые дополнения к брифу

## 24.09.2026 — кнопка после добавления в корзину

После успешного добавления выбранного SKU кнопка становится зелёной «Перейти в корзину», повторное нажатие открывает /cart без нового добавления. Состояние общее для основной и мобильной кнопок и восстанавливается по серверной корзине. Другой SKU проверяется отдельно. При явном изменении количества возвращается действие добавления выбранного количества; количество уже сохранённой строки можно менять в корзине.

## 24.09.2026 — автоматическая Яндекс.Карта

Владелец прямо поручил убрать подтверждение для Яндекс.Карт. Удаляются отдельный checkbox, кнопка включения и запись согласия при загрузке; SDK запускается после выбора города/загрузки ПВЗ. Это заменяет прежнее поведение карты с отдельным согласием. Подтверждение тестового заказа остаётся. Старые записи ar_service_consents и миграция011 сохраняются; автоматическое включение не записывать как принятое согласие.

> Записи датированы. Позднее прямое решение заменяет раннее по тому же вопросу; текущий результат — [status.md](status.md). Исторические записи об отсутствии доступа не являются сегодняшним запросом к владельцу.

## 21.09.2026 — после подготовки плана

- Пользователь согласовал предложенный план и объём первой версии; следующий выполняемый шаг — два визуальных направления, не все этапы сразу.
- Фотографии можно временно заменять явно обозначенными заглушками.
- При частичной нехватке товара целая строка корзины уходит в предзаказ; между строками — порядок добавления, с показом разделения до подтверждения.
- Таблица товарных данных и совместимости остаётся задачей наполнения; фактические сведения не предоставлены, поэтому не заполнять вымышленную применимость.
- У пользователя есть GitHub-репозиторий; подключение позже, после передачи адреса. Сейчас remote не добавляется.
- Docker используется на этапе среды для новых PostgreSQL/Directus, с отдельными ресурсами. Визуальные прототипы запускаются локально без Docker. Для воспроизводимого запуска Astro контейнер добавляется на этапе среды.

## 22.09.2026 — цены в рублях во всех слоях

Владелец попросил показывать цену в рублях в админке и отдельно уточнил: «в базе сохрани расчет в рублях тоже». Это заменяет прежнее техническое решение о целых копейках. Денежные колонки — numeric(16,2), суммы API/снимков — десятичные строки, расчёты — Decimal в рублях. Например, старые 720000 копеек преобразованы в 7200.00 рубля. Исходный заполненный бриф сохранён без переписывания истории.
