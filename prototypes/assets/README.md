# Происхождение ресурсов

- brand/logo.svg — векторный экспорт materials/brand/1.pdf; logo-inverse.svg — materials/brand/7.pdf. Экспорт pdftocairo, viewBox обрезает только поля страницы. Сами исходные контуры не менялись; версии с полными полями сохранены как *-source.svg.
- placeholder-console.svg — условная иллюстрация-заглушка, созданная для прототипа. Не изображение реального товара.
- fonts/manrope*.ttf — [Manrope](https://fonts.google.com/specimen/Manrope).
- fonts/oswald*.ttf — [Oswald](https://fonts.google.com/specimen/Oswald).
- Шрифты загружены 21.09.2026 из официального fonts.gstatic.com по CSS Google Fonts. Локальные CSS содержат только относительные URL. Лицензии SIL OFL получены из [google/fonts](https://github.com/google/fonts) и сохранены рядом.
