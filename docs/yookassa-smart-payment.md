# Умный платёж ЮKassa

15.10.2026 владелец поручил убрать выбор карты/СБП, оставить одну кнопку с выбором способа на стороне ЮKassa, проверить и опубликовать с сохранением чеков/noindex. Действующий выпуск — status.md.

## Контракт

- Для новых попыток из интерфейса YooKassa сохраняется method=smart. Отсутствующий method в API также означает smart для YooKassa. Это сценарий выбора на стороне провайдера, а не утверждение о фактическом платёжном инструменте.
- POST /payments передаёт точные amount/RUB, capture=true, redirect/return_url, неизменяемый receipt и metadata заказа. payment_method_data/payment_method_id/payment_token/save_payment_method не передаются. Проверяются свой активный магазин, правильный test-контур, фискализация и наличие хотя бы одного способа, поддерживаемого «Умным платежом». Доступные способы определяются подключениями магазина; B2B/электронный сертификат не входят в этот сценарий.
- Для старых card/sbp сохраняются прежние тело, provider_key, method и ссылка. Старые клиенты с явным method остаются совместимыми. Новая команда smart при существующей pending-попытке возвращает её, не создавая второй платёж. Неизвестный исход повторяется с прежним ключом/снимком; смена интеграции не заменяет начатый запрос другим телом.
- Одна кнопка «Перейти к оплате» и пояснение о выборе на странице ЮKassa. У песочницы тоже одна кнопка с тестовой подписью; локальная simulation сохраняет свои имитаторы. Pending показывает продолжение прежней оплаты/проверку статуса. Возврат браузера не подтверждает деньги: прежние GET-сверка, webhook, сумма/магазин/метаданные и складская идемпотентность сохранены.
- Чеки предоплаты, полного расчёта и возврата используют прежние снимки и отдельные фискальные статусы. Новых денежных/фискальных операций при публикации не создавать.

## Схема и совместимость

Новая036 расширяет допустимый method и ar_payment_yoo_snapshot для smart в sandbox/live. В live чек по-прежнему обязателен; smart запрещён для simulation. Данные и применённые001–035 не меняются. После появления smart-попыток откат на обработчик, который знает только card/sbp, недопустим; нужна совместимая версия. Аварийная пауза — прежний opt-in=false без удаления истории и без переключения live на sandbox.
