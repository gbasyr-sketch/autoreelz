# Генерация описаний в форме товара

30.09.2026. Владелец предоставил отдельные ключи DeepSeek/OpenAI и разрешил общий бюджет до **$5 в месяц**, включая пробы. Ключи находятся только в private и серверном env, не в Git. Состояние выпуска — [status.md](status.md).

## Как пользоваться

1. «Товары» → «Добавить товар» или «Редактировать» обычный товар.
2. Укажите название, категорию, варианты и известные характеристики. Для ещё не опубликованной карточки предварительное сохранение не обязательно.
3. Раскройте **«Помощник для описания»**. При необходимости добавьте проверенные сведения в поле «Дополнительные факты для этого текста». Они используются в этой вкладке и сами по себе не публикуются.
4. Нажмите **«Сгенерировать описание»**. Будут подготовлены описание и meta description; ручной SEO-заголовок не передаётся модели и не изменяется.
5. Проверьте и отредактируйте оба текста. **«Применить в черновик»** только переносит их в поля формы. Затем отдельно сохраните черновик или опубликуйте товар.

Виджет показывает общий бюджет, учтённую верхнюю оценку расходов и остаток. «Сгенерировать другой вариант» означает новый платный запрос. После потери связи используйте «Проверить результат запроса»: сохраняется прежний ключ, новый вызов провайдера не отправляется. Неопределённые исходы учитываются по верхней границе до проверки, а не считаются бесплатными.

Если исходные характеристики или ручной текст изменились во время подготовки, применение старого результата блокируется. Сначала подготовьте новый вариант. ИИ может ошибаться: наличие кнопки не заменяет проверку совместимости, комплектности и других фактов.

Старый `/manager/descriptions` остаётся явно обозначенным шаблонным генератором без платных вызовов; он содержит ссылку в новую форму. Комплекты по-прежнему редактируются в CMS, новый помощник предназначен для обычных товаров и их исполнений.

## Доступность сервисов

- **DeepSeek Flash** (`deepseek-flash`): ключ, наличие баланса и доступ к API проверены; с сервера `/models` вернул200. Выбран для запуска.
- **OpenAI GPT-6 Luna**: ключ действителен при проверке с рабочего компьютера; сервер вернул403 `unsupported_country_region_territory`. В серверной конфигурации OpenAI отключён (`AI_TEXT_ALLOW_OPENAI=false`), автоматического переключения на него нет. Адаптер подготовлен и проверяется имитацией; не считать его работающей серверной интеграцией.

Эти проверки доступа не равны проверке качества текста; результаты проб и точный app SHA сохраняются в `artifacts/ai-text/`.

## Контракт и расходы

- `GET /api/manager/product-ai` — доступные сервисы и общий бюджет; `?request=<UUID>` — запрос только его владельца. `POST` принимает `productId`, текущее `data` формы, `notes`, провайдера и `idempotencyKey`. Везде staff/no-store; для POST — Origin/CSRF и64КиБ JSON.
- Провайдер получает только название, категорию, имена/артикулы вариантов, значения характеристик, правила совместимости и дополнительные факты. Не получает цены, остатки, упаковку, фотографии, существующие тексты, ручной title, ключи или сведения покупателей. Значения справочников разрешаются сервером; особенности вариантов переопределяют общие, собственная совместимость заменяет общую.
- Запрос с фактами сохраняется в `ar_ai_text_requests` (миграция013). `input_hash` защищает от повторного использования ключа с изменёнными данными; один ключ одного сотрудника вызывает провайдера не больше одного раза. Сетевой вызов идёт вне DB-транзакции и блокировок каталога/склада.
- Бюджет общий на все поддерживаемые сервисы и сотрудников этого магазина, календарный месяц по Москве. Лимит приложения ограничен сверху согласованными $5. Он относится к запросам AUTO REELZ, а не к расходам аккаунтов провайдеров из других программ.
- Перед вызовом под единой advisory-блокировкой резервируется верхняя оценка: UTF-8 длина входа с запасом на служебные токены, максимум1800 выходных токенов, пиковый тариф без кеша. Факты ограничены24КиБ. После ответа сохраняются счётчики токенов и верхняя стоимость по проверенному тарифу; скидки кеша/непикового времени делают фактический счёт ниже. Это не банковская выписка провайдера.
- Неопределённый исход сохраняет резерв, в том числе при переходе месяца. Повтор возвращает состояние прежнего запроса. Явный отказ4xx учитывается без списания; некорректный/обрезанный, но оплаченный ответ учитывается по usage. Несоответствие usage пределам останавливает новые генерации до проверки.
- Не более20 новых запросов сотрудника за час; проверка готового запроса не тратит новую попытку. Ключ запроса сохраняется в sessionStorage текущего браузера для повтора после сбоя. Сами ключи сервисов доступны только серверу.
- Модели и тарифы фиксированы в `src/server/adapters/ai-text.ts`; произвольный model/base URL от клиента не принимается. При смене модели или тарифа сначала обновить оценку и проверки. OpenAI использует Responses с `store:false`, DeepSeek — Chat Completions без thinking. Нет tools, внешнего поиска или автоматических повторов провайдера.
- Никакая генерация не пишет в каталог, черновики редактора, SEO-title, заказы или склад. Применение — в памяти формы; публикация использует прежний транзакционный редактор.
