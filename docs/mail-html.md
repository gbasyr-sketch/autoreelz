# HTML-письма AUTO REELZ

Подготовлено15.10.2026 по поручению владельца применить согласованные макеты по схеме Pack24 и отправить по одному демонстрационному письму пяти типов на sales@autoreelz.ru. Это не создание заказа, оплаты, отправления или настоящего кода входа.

## Шаблоны и источники

- `mail-templates.ts`: новый заказ/готовность к оплате — подробные; подтверждение оплаты/трек — короткие; код входа отдельно. Макеты переведены в табличную вёрстку с inline CSS, шрифтом Arial и оригинальным инверсным логотипом. Логотип растеризован из существующего SVG в PNG и вложен через CID, без внешнего запроса. Снимок вложения хранится вместе с HTML, не подменяется новым логотипом при повторе.
- `renderOrderMail` получает только серверный снимок заказа: товары/исполнение/количество/цены, получателя, доставку, согласованную дату и срок оплаты. Деньги — точные строки RUB/Decimal через существующий money-модуль. Номер заказа/имя/адрес/примечания/трек/названия экранируются. Фото — только проверенные адреса media/static raster на autoreelz.ru, без токенов/внешних хостов; отправляющий worker их не скачивает. При отсутствии фото остаётся миниатюра-заглушка.
- Создание заказа, подтверждение предзаказа, тестовая оплата и событие shipped ставят соответствующий HTML. Ручное согласование доставки обычного заказа также отправляет готовность к оплате. До подтверждения предзаказа кнопки оплаты нет; после изменения условий читается обновлённая строка в той же транзакции. Срок — expires_at заказа, не новый интервал с момента получения письма. Приглашение к оплате истекает вместе с заказом.
- Ссылки ведут на штатную защищённую страницу заказа; button tracking открывает сведения о доставке там же. Нет magic-login/PSP-токенов/обхода доступа. Демо-кнопки ведут в список заказов без платежа. Чек ЮKassa не подменяется магазинным письмом.
- Тестовый режим явно обозначен; подтверждение sandbox-оплаты сообщает, что реальные деньги не списывались. Исходные EML Pack24, личные данные, их менеджер/фото/телефоны/ссылки оплаты не переносились.

## Очередь и безопасность

Миграция030 добавляет nullable html_body/template_version и inline_assets с ограничениями размера/числа вложений и целостности. Расширен триггер неизменяемости029: HTML/версия/CID-данные SMTP запрещены к изменению. Старые записи не дополняются/не пересылаются. Plain-text body сохраняется; Nodemailer отправляет HTML+text (multipart alternative) и inline PNG из Buffer. File/URL access и debug отключены, вложение проверяется по ожидаемым имени/CID/типу/PNG-сигнатуре. Код входа и письмо сохраняются атомарно; менеджерский тестовый inbox по-прежнему не показывает настоящие SMTP-коды.

MAIL_PROVIDER/политика all-new/фиксированный cutoff и секрет только у worker сохраняются. Идемпотентность/lease/неизвестный исход/ограниченные повторы остаются прежними. Owner-уведомления, получение и отмена сохраняют действующий текстовый вариант: задача охватывает пять согласованных шаблонов.
