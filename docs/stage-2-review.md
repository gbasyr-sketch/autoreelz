# Проверка этапа 2 — направление A

Дата: 21.09.2026. Проверена собранная Astro SSR-витрина на localhost:14322. Node 24.21.0, Astro 7.3.3, @astrojs/node 11.1.6, TypeScript 6.0.3. Браузер: Chrome 153.0.8010.48, Playwright 1.62.1, DPR 1. Телефон эмулировался; физическое устройство не проверялось.

## Прошло

- Astro check: 18 файлов, 0 ошибок, 0 предупреждений, 0 hints. Сборка standalone Node успешна.
- 7 проверок node:test: цена+цвет на одном SKU; наличие+цвет на одном SKU; артикул выбирает нужный SKU и его остаток; чужой SKU не подменяется основным; фиксированные составы/цена/остаток комплектов; неизвестная совместимость; входные ошибки цены/автомобиля.
- Главная/каталог/товар: 375, 768, 1024, 1440 px. Все штатные страницы 200, noindex; нет горизонтального переполнения, JS-ошибок, HTTP-ошибок ресурсов и внешних запросов.
- 18 браузерных сценариев в behavior-check.json: mobile фильтры, пустой результат, исправление цены, поиск без совпадений, явный показ неизвестной совместимости, удаление автомобиля вместе с зависимыми условиями, предзаказ SKU, избранное после reload, корзина/удаление, проверка авто, ошибка количества, фиксированный комплект, целый комплект в предзаказе, 404 неизвестного SKU/товара, клавиатура/Escape/возврат фокуса, reduced motion, ошибка localStorage, работа без JS.
- Вариант с синим SKU в URL выдаёт 5 100 ₽ и выбранную синюю подсветку уже без JS; переход на белый выдаёт 5 300 ₽ и предзаказ. Фильтры без JS отправляются обычной GET-формой.
- Контент и действия обозначены демонстрационными; реальные сообщения/платежи/заказы не создавались.

## Исправлено

- Найденное независимой проверкой смешение SKU в поиске по артикулу: поиск DEMO-HEATER-W раньше мог показать красное исполнение по минимальной цене. Теперь совпадение артикула/названия исполнения ограничивает варианты до фильтрации цены и наличия. Регрессионный тест и браузерная проверка прошли.
- Сокращены отступы в верхней части каталога, чтобы на телефоне раньше появлялись товары. Проверены все четыре ширины после изменения.
- Кнопка применения mobile-фильтров закреплена внизу диалога. Длинный список прокручивается отдельно; GET-форма без JS остаётся доступна в details.
- TypeScript приведён к поддерживаемому диапазону checker; финальные зависимости точно закреплены.

## Ограничения

Это не тесты серверной корзины/оплаты и не приёмка складских гонок. localStorage обслуживает только демонстрацию интерфейса. Производственные роли/сессии/БД/Directus, оплаты, доставка и OTP относятся к последующим этапам. Не проводились полный аудит WCAG, Lighthouse/полевые метрики, публичная индексация, проверка реального ассортимента и юридических текстов. Для отсутствующей совместимости никогда не выдаётся подтверждение применимости.

Независимый агент выполнил чтение кода и воспроизведение дефекта pure-функции; его дополнительный браузерный запуск попал в окно перезапуска сервера. Перечисленные браузерные проверки выполнены главным агентом по работающей сборке.
