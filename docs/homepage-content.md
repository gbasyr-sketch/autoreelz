# Главная и редакционные материалы

29.09.2026: владелец согласовал карусель в верхнем баннере, популярные категории, товарные отзывы, описание магазина и статьи. Направление A и текущие фотографии сохранены.

- `src/pages/index.astro`, `src/styles/home.css`, `src/scripts/home.ts`: два баннера, ручное переключение стрелками/точками/клавиатурой/свайпом. Автопрокрутки нет. Первый баннер — прежние готовые комплекты; иллюстрация подписана как заглушка.
- `src/lib/home.ts`: подбор восьми доступных публичных товаров (два ряда по четыре на desktop), шести наполненных категорий и шести последних недемонстрационных статей. На телефоне товары располагаются по два в ряд. «Популярные категории» — название редакционного блока, не статистика продаж.
- `src/server/home.ts`: только одобренные товарные отзывы опубликованных недемотоваров, без приватных полей. На главной — последние четыре.
- По просьбе владельца при отсутствии настоящих отзывов в staging/local-test показаны четыре вымышленных **товарных** примера: блок отопителя, консоль, воздуховоды и ручка КПП. В каждом указано «Демонстрационный отзыв», есть ссылка на конкретный товар. Тот же пример доступен в его карточке, если настоящих отзывов там нет. В production примеры не выводятся. В БД отзывы, заказы и покупки для этого не создаются; рейтингов и вымышленных дат нет. Тексты примеров — в `demoProductReviews`, они привязываются к первому доступному реальному товару соответствующей категории.
- Описание магазина — CMS → страницы → `about`; главная берёт первые два абзаца. Статьи — CMS → статьи: текст, категория, обложка, статус и дата. Публикация будущей датой скрывает материал до неё.

## Статьи

Добавлено восемь авторских материалов. Исходный редакционный пакет — `content/homepage-articles-2026-09.json`; это снимок первой загрузки, **не автоматическая синхронизация и не seed**. Последующие правки владельца в CMS не перезаписывать этим файлом. Идентификаторы — `artifacts/homepage/content-import.json`.

Видео «Переделка салона приора 1 под приора 2» вставлено по предоставленному URL RUTUBE, с его превью. Автор канала autoreelz; в описании источника указан Tesla monitor auto, атрибуция сохранена. Статья — введение и подготовка к просмотру по доступным метаданным, не расшифровка и не проверенная пошаговая инструкция монтажа. Видео не скачивается, внешний плеер включается по кнопке.

По записи DanCHIK на Auto.ru написана самостоятельная краткая памятка: исходная комплектация, состав деталей, вопросы установщику. Источник указан ссылкой; чужие фотографии, текст и распиновки не копировались. Применимость деталей по статье не обещается.

Остальные темы: подбор детали, состав комплекта, цвет подсветки, поверхность, ПВЗ СДЭК, наличие/предзаказ. Обложки — собственные фотографии каталога, превью предоставленного видео либо декоративные иконки. Исходная демонстрационная статья сохранена.

Тело статьи остаётся экранированным простым текстом: отдельный абзац `## Заголовок` превращается в подзаголовок, HTTPS-ссылки — в ссылки. HTML не исполняется. Редактирование не требует вставки iframe/HTML.

## Проверка и откат

`npm run check`, `npm test`, `npm run build`; интерактивная проверка главной на desktop/mobile, переход от отзыва к товару, ссылки всех статей и включение видео. Полный локальный DB-QA требует Docker. Миграций в этой задаче нет.

Перед CMS-записью сделан отдельный серверный pg_dump, путь в отчёте импорта. Проверена читаемость архива, полное восстановление не выполнялось. Не откатывать всю рабочую БД ради текстов: при необходимости архивировать только восемь новых статей по их ID и вернуть прежний текст about из приватного before-файла. Не повторять импорт вслепую.
