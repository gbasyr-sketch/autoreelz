## Доказательства

- Владелец и редактор вошли через настоящую форму Directus. Каждый создал через формы два раздела, категорию и подкатегорию, затем перенёс категорию с дочерней подкатегорией в другой раздел.
- Через CMS API созданы временные характеристики с наследованием от раздела, товар с опубликованным SKU и явной отметкой демоданных. Код витрины и существующие товары/остатки не менялись.
- В отдельном браузерном контексте с **полностью выключенным JavaScript** проверены настоящие HTML-ссылки категорий, переход по ссылке подкатегории, хлебные крошки, фильтрация с совпадающим и отсутствующим значением.
- После сохранения переноса товар исчез из результатов старого раздела и появился в новом. Изменились хлебные крошки и набор унаследованных фильтров; новый фильтр находит товар. Перезапуск и пересборка не требовались.
- При подборе автомобиля товар без подтверждённой применимости скрыт по умолчанию. Он появляется лишь после перехода по ссылке включения неизвестной совместимости и подписан «Совместимость уточняется».
- Смена родительского раздела на черновик скрывает дочерние категории из навигации, карточка товара возвращает 404. Возврат публикации выполнен до удаления фикстур.
- Редактор получает 403 при чтении заказов, покупателей, тестовой почты, одноразовых кодов и web-сессий; управление схемой и запись склада ему запрещены. Анонимный доступ к проверенным частным коллекциям и CMS API каталога также возвращает 403.
