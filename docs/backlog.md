## Не выдавать за готовое

- Семь проверок галереи/избранного не являются полной новой приёмкой торговли.
- Срок жизни cookie30дней не определяет срок хранения всех заказов/логов/копий. Политику хранения ещё предстоит реализовать.
- Резерв30минут — текущая техника тестового магазина; юридический момент акцепта/предзаказа должен быть согласован до реальных продаж.
- Контроль `pg_restore --list` проверяет читаемость архива, не доказывает успешное полное восстановление сервера.
- Мобильные замеры этапа6 предшествуют WB-фотографиям; обещаний полевого INP/нагрузки пока нет.
