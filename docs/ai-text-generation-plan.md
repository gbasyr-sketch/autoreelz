## Следующий шаг

Подготовлен `private/ai-texts.env`, права0600, исключён из Git. Владелец может заполнить `OPENAI_API_KEY` и/или `DEEPSEEK_API_KEY`. Файл пока **не читается приложением**, `AI_TEXT_PROVIDER=disabled`. После реализации и проверок подключать в пределах согласованного общего бюджета; отдельное повторное согласование тех же расходов не требуется.

Владелец согласовал **до $5 в месяц**. Это общий предел на оба сервиса, включая пробу. В приватном файле месячный лимит5, внутренний предел пробы1 (часть месячного лимита, не дополнительный бюджет). Реальные вызовы пока не запускались. Секретные значения не писать в документацию, логи и сообщения.

## Предлагаемое подключение

1. Подготовить оба адаптера, основной выбрать после проверки доступа и примеров. Автоматически отправлять один товар сразу в оба сервиса или переключаться на платный резерв без настройки не нужно.
2. Добавить кнопку генерации в новую форму товара. Источник - текущие введённые данные, включая ещё не опубликованный черновик, общие характеристики и отличия исполнений. Совместимость включать только с явно заданным статусом и условиями. Владелец должен видеть, какие сведения отправятся.
3. Генерировать только описание и meta description. Ручной SEO-заголовок и торговые поля не менять. Не передавать сведения покупателей, ключи, заказы и остатки. Не выводить из фото неподтверждённые технические свойства.
4. Результат показывать рядом с текущими текстами, с возможностью правки. «Применить в черновик» заполняет поля формы; на витрину изменения попадают только по отдельной публикации товара. Устаревший результат после правки исходных характеристик не применять без проверки.
5. Вызов API выполнять вне транзакций/блокировок каталога. Защита staff/Origin/CSRF, ограничение длины и частоты, таймаут, запрет неоднозначных автоматических повторов платного запроса. Учёт расходов с резервированием верхней границы запроса до вызова; бюджет кабинета провайдера не считать гарантированным ограничителем приложения.
6. После получения ключей и согласованного лимита сравнить тексты на пяти разных товарах. Оценить фактическую точность, естественный русский язык, отсутствие повторов/выдуманных обещаний, время и стоимость. Результаты сначала только в предварительном просмотре.

Это план, не отчёт о реализованном подключении. API для новой формы, учёт расходов и реальные адаптеры ещё предстоит написать и проверить. Старый раздел «Описания» не переключать незаметно на платные запросы.

## Проверенные кандидаты на 30.09.2026

| Сервис | Кандидат | Что известно |
|---|---|---|
| OpenAI | `gpt-6-luna` | Модель для небольших массовых задач; Standard: $0.10 за1млн входных и $0.50 за1млн выходных токенов при коротком контексте. Качество именно для этих товаров не проверено |
| DeepSeek | `deepseek-flash` | Текущая версия V4.1 Flash; $0.15–0.30 за1млн входных токенов без кеша и $0.60–1.20 за1млн выходных, в зависимости от времени. Поддерживает JSON и Responses API. Качество именно для этих товаров не проверено |

Цены датированные, без пересчёта в рубли и без обещания стоимости конкретной карточки. Перед платной проверкой сверить тариф, выбранный режим и доступные в аккаунте модели. Для коротких описаний начать с режима без рассуждений, если он поддерживается выбранной моделью; точные параметры проверить перед реализацией.

OpenAI: [модель](https://developers.openai.com/api/docs/models/gpt-6-luna), [тарифы](https://developers.openai.com/api/docs/pricing), [генерация текста](https://developers.openai.com/api/docs/guides/text), [поддерживаемые страны](https://developers.openai.com/api/docs/supported-countries). Россия не включена в опубликованный список; наличие кабинета/ключа само по себе не снимает ограничения. Не строить подключение на обходе ограничений.

DeepSeek: [модели и тарифы](https://api-docs.deepseek.com/quick_start/pricing/). Доступ конкретного аккаунта и сервера требуется проверить отдельно.
