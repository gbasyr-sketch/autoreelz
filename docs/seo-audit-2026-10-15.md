## Что исправить

1. **В первую очередь — адаптивные изображения.** Сохранить оригиналы и выдавать уменьшенные WebP/AVIF через srcset/sizes; отдельные размеры для карточек, миниатюр и основного фото. В каталоге изображение1536×1024 отображается примерно165px шириной, передаётся около199КБ. Lighthouse оценивает потенциальную экономию изображений около1,42МиБ на главной,1,86МиБ в каталоге и1,04МиБ в товаре. Это оценка инструмента, не измеренный результат будущего исправления. Не уменьшать исходники инфографики/библиотеки и не менять фотографии владельца.
2. **Добавить превью ссылок.** Общие og:title, og:description, og:url, og:type и og:image; для товара — его опубликованное фото, для статьи — обложка, fallback для остальных страниц; согласованные Twitter Card. Это улучшение отображения ссылок в соцсетях/мессенджерах, не обещание роста позиций.
3. **Развести заголовки двух разных карточек козырька.** Пути `kozyrek-pod-planshet-9-dyuymov-v-stile-priora-2-dlya-priora-1-chernyy-glyanets` и `...-chernyy-matovyy` имеют одинаковые H1 и title. Добавить подтверждённое различие исполнения в SEO-title; текущие свойства и решение об объединении SKU не менять автоматически. Повторы title между SKU одной общей canonical-карточки ожидаемы и не считаются отдельной ошибкой.
4. **Различить пагинацию.** У `/catalog?page=2/3` title совпадает с первой страницей, аналогично `category=interior&page=2/3`. Добавить номер страницы в итоговые метаданные; отдельные canonical уже работают. Это редакционное улучшение, не блокировка индексации.
5. **Уточнить description главной.** Сейчас «AUTO REELZ: детали автомобильного интерьера.», такой же текст у `/cars`. Написать полезное описание фактического ассортимента без выдуманных преимуществ и обязательного количества знаков. `/cars` по действующему контракту остаётся noindex.

Перед открытием поиска также заменить/скрыть согласованным способом оставшиеся демонстрационные блоки главной (заглушка первого баннера, вымышленные отзывы) и проверить готовность демонстрационной статьи `/blog/how-selection-works`. Они сейчас честно помечены; не выдавать их за реальные отзывы/контент и не удалять автоматически. Для статьи с видео VideoObject отсутствует в фактических ответах; добавлять лишь при заполненных настоящих метаданных ролика по действующему контракту. Organization с фактическим брендом/логотипом/контактами можно добавить отдельным небольшим улучшением, без фиктивного физического магазина, рейтинга и соцпрофилей.
