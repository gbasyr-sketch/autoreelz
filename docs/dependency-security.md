Новая регрессия проверяет опасные формы экспорта на всех этих границах: обработчики событий/внешние изображения не проходят, обычный текст и безопасная ссылка сохраняются. Проверка реального entry редактора `tests/content-editor-bundle.mjs` подтверждает отсутствие полного Quill/formula/video и наличие10 используемых форматов.

Источники: [исследование CVE-2025-15056](https://fluidattacks.com/advisories/diomedes), [официальный модульный импорт](https://quilljs.com/docs/installation), [advisory без исправленной версии](https://github.com/advisories/GHSA-v3m3-f69x-jf25). ## Важное уточнение о кэшировании

Сопровождающий http-cache-semantics оспаривает исходный отчёт и закрыл issue: Set-Cookie сам по себе не запрещает HTTP-кэширование. Поэтому переход4.3.0 и исчезновение предупреждения **не выдаются за доказательство исправления конкретного сценария утечки**. Astro использует библиотеку для удалённых изображений и проверяет storable() перед сроком хранения; вызов satisfiesWithoutRevalidation() в этой цепочке не найден. Страницы/приватные API магазина сохраняют no-store, персональные ответы в общий кэш не помещаются. [Обсуждение сопровождающего](https://github.com/kornelski/http-cache-semantics/issues/56).
