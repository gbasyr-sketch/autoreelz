# SEO: правила и проверка этапа 6

23.09.2026. Реализация — SSR Astro. Политика в `src/lib/seo.ts`, серверный допуск в `src/server/seo.ts`. Локальный магазин закрыт от индексации; SEO-флаг не включён. Проверки и ограничения — [stage-6-review.md](stage-6-review.md).

## Матрица маршрутов

| Страница | Публичная политика | Canonical / HTTP |
| --- | --- | --- |
| Главная | index | https://autoreelz.ru/; 200 |
| Каталог и опубликованная категория | index, если на странице есть реальные товары с фото | Собственный URL; category сохраняется |
| Пагинация каталога/блога | index для содержательных страниц | Собственный page=N; page=1 нормализован; за пределами —404 |
| Поиск, сортировка, произвольные фильтры | noindex,follow | Категория/страница без утилитарных параметров; пустой поиск —200 |
| Опубликованный товар | index для реального товара с фото | Базовая карточка; ?sku выбирает исполнение в серверном HTML |
| Демо-товар/статья, черновик юридического текста | noindex,follow | Базовый URL; в sitemap отсутствует |
| Статья, категория/тег блога | index для непустого реального контента | Собственный URL, архивы с HTML-пагинацией |
| Информационная страница | index после снятия признака проекта текста | Собственный URL |
| /cars и /cars/slug | noindex,follow | Собственный URL: пока это формы подбора без проверенных редакционных посадочных |
| Корзина, checkout, избранное, кабинет, manager, заказы, API | noindex,follow + права доступа | Canonical не назначается; приватные ответы no-store |
| Неизвестный товар/SKU/категория/страница, скрытый родитель | noindex | 404; без подмены стандартным SKU или главной |
| Неверное значение фильтра | noindex | 400 с объяснением |
| Старый slug товара/категории | Редирект только на опубликованную сущность | Прямой 301 на текущий slug, без цепочки; выбранный sku сохраняется |

На localhost **все** страницы дополнительно получают noindex в HTTP/meta; robots — Disallow:/. Публичная индексация допускается лишь при одновременных `SEO_INDEXING_ENABLED=true`, `STORE_MODE=production`, `APP_ORIGIN=https://autoreelz.ru` и совпадении origin запроса. Это подготовленный контракт, а не инструкция включить production сейчас. Для публичных noindex-страниц robots не запрещает обход: бот должен прочитать директиву. Noindex не заменяет авторизацию.

## Метаданные и разметка

Ручной SEO-title выводится точно, без автоматической замены генератором или добавления бренда. Description отдельный; если не заполнен, используется краткий текст конкретного товара/страницы. Перед запуском редактор проверяет реальные тексты на пустоту, повторы и фактические ошибки. Демо-контент не является итоговым наполнением.

Product/Offer описывает точный SKU, артикул, десятичную строку RUB и InStock/BackOrder; фиксированный комплект получает рассчитанное предложение без вымышленного артикула. ProductGroup связывает исполнения, canonical остаётся общей карточкой. `variesBy` используется только для реально различающихся стандартных свойств color/size/material/pattern. Подсветка и поверхность остаются именованными PropertyValue, не выдаются за цвет самого изделия. Неизвестные и демонстрационные значения исключены из свойств разметки/фида. Рейтингов, GTIN, выдуманного производителя и сроков доставки нет.

BreadcrumbList отражает навигацию. Article содержит фактические заголовок/описание/дату/изображение, без придуманного автора. VideoObject появляется лишь при заполненных названии, описании, собственном превью и дате ролика; длительность необязательна. Эти поля редактируются в CMS. Ссылка, текст и превью видны до клика, внешний VK/Rutube iframe — после согласия. При недоступности провайдера ссылка остаётся. Это не гарантия индексации видео или расширенного сниппета. Статьи связываются с товарами через CMS.

JSON-LD экранирует HTML-разделители. Цены/выбор SKU проверяются без JavaScript. Изображения содержат размеры и alt; вместо реальных фотографий пока разрешённые владельцем заглушки.

## XML и YML

`/sitemap.xml` локально — корректный пустой XML. В production — только разрешённые canonical URL с реальными данными, включая последние страницы; без SKU-query, фильтров, черновиков и приватных URL. Несуществующий lastmod не выдумывается.

`/feed.yml` локально возвращает 503. Для разрешённой production-среды дополнительно нужны одобренное `YML_COMPANY_NAME` и реальные опубликованные предложения с медиа. Выгрузка в RUB, одна строка на физический SKU либо фиксированный комплект; изображения/URL/цена/наличие берутся из той же модели, что витрина. Нет фиктивных сроков, старых цен и скидок. Предзаказ available=false с пояснением согласования условий до оплаты. Внутренний артикул — param «Артикул», пока не подтверждён vendorCode производителя.

Миграция 009 добавила стабильный положительный числовой `ar_categories.feed_id`: YML не принимает внутренний UUID категории. UUID и связи БД сохранены, поле автоматически заполняется и скрыто от редактирования. Иерархия parentId выводится через те же feed_id. XML экранирует значения и удаляет недопустимые управляющие символы. Фактическую приёмку Яндексом необходимо выполнить на финальных данных и в аккаунте владельца.

## Доказательства и ограничения

10 unit-тестов SEO, 7 браузерных групп на отдельной QA-базе: пагинация 13 товаров, ручной title, SSR5300.01RUB, canonical, 301 после двух переименований, 404, локальная защита от индексации, VideoObject и отказ провайдера,14 предложений YML. XML разобран независимым парсером. Файлы в `artifacts/stage-6/`: seo-browser.json, qa-product-schema.json, qa-sitemap.xml, qa-feed.yml, xml-validation.json. QA-примеры явно синтетические, не данные реального ассортимента.

Google Rich Results Test при проверке кода потребовал вход в аккаунт; validator.schema.org не открылся с ERR_SOCKET_NOT_CONNECTED. Внешняя валидация **не пройдена**, это ограничение отражено в external-validation.json. Публикация localhost и отправка URL в поисковые системы не выполнялись. Search Console, Яндекс Вебмастер, merchant-приёмка, полевой INP и реальное воспроизведение конкретных VK/Rutube роликов остаются до запуска.
