# Подтверждённые дополнения к брифу

## 21.09.2026 — после подготовки плана

- Пользователь согласовал предложенный план и объём первой версии; следующий выполняемый шаг — два визуальных направления, не все этапы сразу.
- Фотографии можно временно заменять явно обозначенными заглушками.
- При частичной нехватке товара целая строка корзины уходит в предзаказ; между строками — порядок добавления, с показом разделения до подтверждения.
- Таблица товарных данных и совместимости остаётся задачей наполнения; фактические сведения не предоставлены, поэтому не заполнять вымышленную применимость.
- У пользователя есть GitHub-репозиторий; подключение позже, после передачи адреса. Сейчас remote не добавляется.
- Docker используется на этапе среды для новых PostgreSQL/Directus, с отдельными ресурсами. Визуальные прототипы запускаются локально без Docker. Для воспроизводимого запуска Astro контейнер добавляется на этапе среды.
