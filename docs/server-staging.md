## Размещение

Сервер Ubuntu22.04.5 x86_64,4CPU/8 ГБ RAM/79 ГБ диск (54 ГБ свободно при проверке), ISPmanager. Nginx/Apache/почта уже работают. Для нового магазина создан отдельный пользователь `autoreelz2026` (UID1018), каталог `/srv/autoreelz2026` и rootless Docker29.8.1 с cgroupv2. Compose5.5.1 и Buildx0.37.1 установлены только этому пользователю; бинарники проверены по опубликованным SHA256. Из apt добавлены только uidmap/slirp4netns/libslirp0, без обновлений/удалений прежних пакетов и перезапуска прежних служб.

Compose-проект `autoreelz2026-release`, файлы `infra/release/compose.yaml` + `ispmanager.yaml`. Edge слушает только 127.0.0.1:14324, внешний HTTPS остаётся за Nginx. Витрина защищена отдельным паролем. `/cms/admin` обслуживает Directus с собственным входом: двойной Basic Auth мешает Bearer API Studio, поэтому для `/cms/*` используется штатная авторизация CMS. БД/CMS/web не публикуют отдельные порты.

`STORE_MODE=staging` разрешает только тестовые адаптеры на точном HTTPS-origin `https://autoreelz.ru`; production по-прежнему их блокирует. Поиск закрыт от индексации даже при случайном SEO_INDEXING_ENABLED=true. Базовая покупка на сервере сначала остаётся имитацией; ЮKassa ещё не подключена к checkout, ключей тестового магазина нет.

## Переключение и откат

Владелец подтвердил, что сам удалил прежний сайт из ISPmanager во время работы. Первоначальный vhost исчез до нашего переключения и нами не изменялся. Новый маршрут создан отдельно: `/etc/nginx/conf.d/autoreelz2026.conf`. Перед установкой проверено отсутствие другой конфигурации домена; nginx -t прошёл, reload выполнен без остановки служб. Остальные vhosts не менялись. Повторное добавление autoreelz.ru как обычного сайта ISPmanager может создать конфликт маршрутов; этим магазином управлять через его Compose и отдельную конфигурацию.

Откат маршрута: убрать только наш conf.d/autoreelz2026.conf после сохранения его копии, выполнить nginx -t и reload. Прежний сайт владелец удалил самостоятельно, поэтому его восстановление не является автоматическим откатом. Для отката приложения использовать предыдущий совместимый image digest, не перезаписывать БД. TLS-файлы нового домена находятся отдельно в `/etc/ssl/autoreelz2026`; другие сертификаты не изменялись.
