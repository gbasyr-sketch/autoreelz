# Страницы и статьи в manager

03.10.2026 владелец выбрал Quill после сравнения бесплатных редакторов и поручил реализацию. Quill2.0.3 (BSD-3-Clause), sanitize-html2.18.0 (MIT) локально включены в сборку, без CDN/подписки/API-ключа.

- `/manager/content`: отдельные списки статей/страниц, поиск и статусы. `/manager/content/edit?kind=article|page&id=…` — единая форма.
- Заголовки H2/H3, выделение, списки, цитаты, ссылки, выравнивание, фото внутри текста. Обложка, ссылки на видеоRUTUBE/VK, SEO, категории/теги и связанные товары статьи; признаки юридического/проектного текста страницы сохраняются.
- Общая библиотека/загрузка фотографий; вставка в текст с alt и шириной. Фото только через собственное хранилище, внешние/dataURL не сохраняются. Приватные изображения черновика не публикуются через `/media`.
- Черновик отделён от опубликованной записи. Публикация, архив/восстановление, сброс черновика: версия/хэш актуального материала и связей, идемпотентность, история действий. При конфликте CMS требуется перечитать/сбросить черновик; изменений не затирать автоматически.
- Новая миграция019: формат текста plain/html, таблицы черновиков/аудита и права серверной роли. Старые plain-тексты не мигрируются вHTML автоматически. После явной публикации Quill сохраняется разрешённый HTML; при каждом публичном выводе он повторно очищается. Скрипты/iframe/произвольные стили не допускаются.
- Видео выводится прежним отдельным проигрывателем с включением по нажатию. Slug/history и отложенные даты публикации остаются прежними. Не создавать/переписывать реальные материалы ради проверки.
- Проверки: нормализация/санитизация/XSS, черновики/повторы/конфликты/связи/права фото на отдельной QA-БД, UI375/768/1440, опубликованное чтение без изменения существующего контента.

## Инструкция владельцу

1. Откройте [Контент](https://autoreelz.ru/manager/content). Выберите «Статьи» или «Страницы магазина», затем существующий материал либо кнопку добавления.
2. Заполните заголовок и краткое описание. Текст редактируется в Quill: заголовки, выделение, списки, ссылки и цитаты. Панель форматирования остаётся видимой при прокрутке.
3. Поставьте курсор в нужное место и выберите «Загрузить фото» или «Фото из библиотеки». Укажите alt, ширину и при необходимости подпись. Фото вставится отдельным абзацем; нажатие на него открывает параметры. Обложка статьи выбирается отдельно.
4. Дополнительные разделы содержат категорию/теги, связанные товары, видео и SEO. Категорию и тег можно создать здесь же. Даты указываются по Москве; будущая дата откладывает появление статьи.
5. «Предпросмотр» показывает текущую форму без сохранения. «Сохранить черновик» сохраняет работу отдельно от сайта. «Опубликовать» применяет изменения к витрине.
6. «Удалить материал» перемещает его в удалённые. Восстановление возвращает только в черновик; публикация остаётся отдельным действием.

При конфликте с CMS не перезаписывайте материал вслепую: перечитайте и сравните изменения, затем при необходимости сбросьте черновик. Фотография из закрытого черновика не становится публичной сама по себе; изображение, уже опубликованное в другом товаре/материале, остаётся общедоступным.

## Эксплуатация и проверки

Источник: [Quill Quickstart](https://quilljs.com/docs/quickstart/). Лицензии сохраняются в установленных npm-пакетах. Для Quill2.0.3 зарегистрирован [CVE-2025-15056](https://github.com/advisories/GHSA-v3m3-f69x-jf25) в экспорте HTML. Поэтому `getSemanticHTML()` не считается доверенным: перед сохранением, предпросмотром, загрузкой черновика и публичным выводом используется серверный список разрешённых тегов/атрибутов. Нельзя обходить `safeRichHtml()` или вставлять экспорт непосредственно через `innerHTML`. Фото — только локальные UUID, видео — прежний отдельный плеер. Проверены скрипты, обработчики событий, схемыURL, стили, внешние изображения и ложные ссылки на медиа внутри экранированного текста.

Обновление зависимостей отслеживать отдельно: аудит также показывает неизменённую цепочку Astro → http-cache-semantics. Автоматическое `npm audit fix --force` не применять: оно предлагает несовместимый откат framework. Текущие версии — package-lock.json.

Проверки выпуска:121 быстрый тест passed/8 skipped;30 DB-проверок контента, библиотеки и редактора товаров; настоящий вход и запись/публикация на отдельной QA-БД; интерфейс375/768/1440 с тестовымиAPI. Публично прочитаны7 страниц и9 статей, проверены русский интерфейс, библиотека и предпросмотр1440/375 без сохранения/загрузки. Хэши существующего содержимого, дат, SEO, видео и связей совпали до/после. QA-базы, preview и туннель удалены. [Выпуск](../artifacts/content-editor/deployment.json).

После первых публикаций вHTML откат приложения к версии до019 покажет разметку текстом, а старая библиотека не знает ссылок новых черновиков. Для отката нужна совместимая версия; опубликованные тексты автоматически не конвертировать обратно. Миграции001–019 неизменяемы.
