# Лицензия Directus OIG

Состояние, подтверждённое предыдущими активациями23.09.2026: OIG используется для нового AUTO REELZ локально и на сервере. Ключ принят владельцем; платное расширение лицензии не нужно. Текущие технические проверки подключения не являются новой проверкой юридических условий гранта.

## Сохранить

- Серверный PUBLIC_URL: `https://autoreelz.ru/cms`.
- Локальная среда: `http://127.0.0.1:28055`.
- TELEMETRY=true — условие принятого гранта. Не отключать при повторном setup.
- Ключ/токен хранятся штатно в Directus DB; резерв ключа — `private/directus-oig-key.txt`. Не Git и не app env в отчёте.

Состояние лицензии смотреть через Settings → License/API администратора без вывода ключа/токена. Числа коллекций/пользователей в старых отчётах — снимок того этапа, не текущий лимит.

## Изменение среды

Перезапуск той же БД с тем же PUBLIC_URL не означает новую заявку. Для смены URL или восстановления на другом хосте сначала проверить текущую штатную процедуру привязки; не удалять активированную БД и не расходовать активации автоматически. Если требуется деактивация/повторная активация, учитывать действующую среду и разрешённую задачу.

QA-наборы создают временные SQL-клоны без запуска лицензированной CMS. Не активировать OIG на одноразовых копиях. Их дампы могут содержать лицензионные секреты.

Сохранить доступ к licensing.directus.com и включить состояние лицензии в будущий мониторинг. Условия льготного периода/offline и количество допустимых активаций проверять по актуальной документации перед изменениями, а не считать старую запись гарантией навсегда.

Источники для такой проверки: [лицензирование](https://directus.com/docs/licensing/overview), [FAQ OIG](https://directus.com/oig/faq), [договор](https://directus.com/terms/open-innovation-grant). Аккаунт/ключ заново у владельца не запрашивать, если доступный приватный материал достаточен.
