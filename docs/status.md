## Что работает

- Astro SSR/TypeScript/PostgreSQL/Directus, светлая витрина и CMS. Каталог, SKU, комплекты, совместимость, точные десятичные рубли, общий склад компонентов и предзаказы. Семь страниц, блог/автомобили, избранное, проверенные отзывы/модерация, кабинет владельца и SEO. Подробная приёмка — [stage-6-review.md](stage-6-review.md).
- ЮKassa sandbox: redirect на карту, проверка по API, устойчивые попытки, настоящий webhook и резервная worker-сверка. Два платежа4900₽ и сквозной СДЭК-платёж2190₽ проверены. Реальные деньги/чеки не включены.
- СДЭК: справочники РФ, выбор ПВЗ/курьера, проверка пунктов/упаковки, tariff136/137. Сумма/тариф/пункт сохраняются в заказе; цены браузера не доверяются. Сеть вне SQL-блокировок; обычный заказ и предзаказ рассчитываются отдельно. Расчёт5минут, ошибки/неизвестная упаковка — ручное уточнение до оплаты.
- Яндекс.Карты по выбору владельца: маркеры, кластеры, список/поиск, код/адрес/часы выбранного ПВЗ. Ключ в private/yandex-maps.env и окружении web, вне Git; JS API получает браузерный ключ штатно. Публичный доступ разрешён владельцем.
- После выбора ПВЗ цена доставки и итог появляются рядом с картой и в блоке корзины, без заполнения контактов. При изменении выбора старая сумма сразу убирается; запоздалые ответы игнорируются. Предварительный расчёт не создаёт заказ/резерв. Перед подтверждением выполняется полный расчёт ещё раз.
- На сервер добавлен «Блок отопителя Гранта», артикул «гранта зеленая»,1800₽,10шт. по данным владельца; одна упаковка200г/220×100×40мм. Фото-заглушка, точная совместимость не выдумана. Остальные4 товара/7SKU — демоматериалы. Серверный каталог не заменять локальными сидами.
- CMS https://autoreelz.ru/cms/admin и /manager требуют собственного входа. Доступы — private/server-access.md. Публичный тур https://autoreelz.ru/muzey/ сохранён.
