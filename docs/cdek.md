# СДЭК и выбор ПВЗ

Состояние на07.10.2026: **реальные справочники и калькулятор подключены к публичному checkout; карта — OpenStreetMap/Leaflet**. Создание отправлений, этикеток и вызов курьера не реализованы. [Контракт](cdek-checkout-contract.md) · [Текущее состояние](status.md).

## Настройки

Договор/API предоставлены владельцем. `private/cdek.env` содержит CDEK_CLIENT_ID/CDEK_CLIENT_SECRET и отправителя; не печатать значения. Файл не подхватывается web автоматически: в Compose должны быть переданы соответствующие runtime-переменные.

Отправитель: MKHCH13, Махачкала, пр-т Петра Первого,83; город442. Это место отправления, а не согласованный юридический адрес/адрес возвратов.

## Рабочий сценарий

Город/регион → пункт на карте/в списке либо адрес курьера → предварительная цена без контактов → полный quote → отдельные заказы для наличия/предзаказа. Тарифы136/137; стоимость приходит из СДЭК, клиентский price не доверяется. Смена выбора очищает старую сумму; запоздалый ответ не заменяет новый. Quote живёт5минут.

07.10 владелец выбрал OpenStreetMap. На сервере `PICKUP_MAP_PROVIDER=osm`: используется уже включённый в приложение Leaflet1.9.4. Карта появляется автоматически после выбора города, без отдельного подтверждения. Маркеры/кластеры показывают координаты СДЭК, выбор синхронизирован со списком, кодом и адресом. При ошибке подложки или отсутствии координат доступен список. OSM не предоставляет ПВЗ и не рассчитывает доставку.

Тайлы браузер получает с `https://tile.openstreetmap.org/{z}/{x}/{y}.png`; видимая атрибуция OpenStreetMap, штатное HTTP-кеширование и Referer сохраняются. По уточнению владельца07.10 стандартный префикс Leaflet (ссылка и флаг) отключён через `map.attributionControl.setPrefix(false)`; подпись © OpenStreetMap contributors остаётся. Ключ не нужен. [Условия OSM](https://operations.osmfoundation.org/policies/tiles/) проверены07.10: сервис без гарантии доступности, без массового скачивания/офлайн-карт. При росте нагрузки пересмотреть поставщика тайлов. Внешнему серверу видны технические данные запроса; контакты покупателя и адрес курьера туда не отправляются, геолокация не запрашивается. Учесть фактического поставщика при подготовке документов B01.

Яндекс-адаптер и приватный ключ сохранены для обратимости, но на checkout не загружаются и ключ не передаётся. Переключение выполнено только runtime-настройкой и пересозданием web, без сборки, миграций и изменений каталога. [Запись переключения](../artifacts/osm-map/deployment.json).

## Упаковка

БД хранит массу в граммах, размеры в миллиметрах; клиент переводит размеры в см для СДЭК. Масса/коробка одного SKU не распространяется автоматически на2шт./комплект. Если нет точного правила или API не ответил — стоимость уточняет менеджер до оплаты, не ноль.

Первый артикул «гранта зеленая»: цена1800₽ и исходный приход10шт. предоставлены владельцем; упаковка200г,220×100×40мм. Два фото позже добавлены из WB. Остаток динамический, старое число10 не восстанавливать. После [импорта WB](wb-catalog-import.md) добавлены30 упаковок единичных SKU, но не правила всех составов.
