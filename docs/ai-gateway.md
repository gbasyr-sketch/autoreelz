# Отдельный шлюз генерации

09.10.2026 владелец поручил подключить сохранённый OpenAI-ключ через свой сервер в Нидерландах89.124.96.238. На сервере работает Amnezia; её файлы, контейнер, маршруты и firewall не изменять. Старый адрес89.124.96.1 был ошибочным. Вход root по отдельному SSH-ключу `private/ssh_netherlands_ed25519`, закреплённый host key — `private/netherlands_known_hosts`; пароль не сохранялся в файлы. По просьбе владельца публичный ключ добавлен в root authorized_keys с сохранением прежних строк.

## Устройство и границы

- Магазин/БД/журнал расходов остаются на91.200.150.79. Только запрос OpenAI направляется на `https://89.124.96.238:14446/v1/responses` и далее на фиксированный `https://api.openai.com/v1/responses`. Это отдельный HTTPS-шлюз, не изменение VPN/маршрута всей машины.
- Новый системный пользователь `autoreelz-ai` без входа, код `/opt/autoreelz-ai-gateway/server.py`, unit `autoreelz-ai-gateway.service`. Python3 стандартной библиотеки; новых пакетов/GPU/Docker-контейнеров на NL не требуется. Лимиты96MiB/25%CPU/16tasks, не более2 одновременных соединений. systemd включает автозапуск, read-only filesystem/no-new-privileges; изменять эти ограничения без причины не нужно.
- Вход разрешён только с91.200.150.79 и127.0.0.1, дополнительно нужен случайный64hex `X-AutoReelz-Gateway`. Секрет в `private/nl-gateway.env`, серверном `server.env` и NL `/etc/autoreelz-ai-gateway/service.env`0600. OpenAI-ключ не хранится на NL: приходит из web в памяти по защищённому соединению. Ключи/тексты/ответы не журналируются шлюзом.
- Публичный TLS-сертификат — `src/server/ai-gateway.crt`, закрытый ключ только NL `/etc/autoreelz-ai-gateway/server.key`,0640 root:autoreelz-ai. Сертификат доверяется только этому конкретному HTTPS-запросу в `ai-gateway.ts`; глобальные CA/TLS-настройки не ослабляются. SAN содержитIP89.124.96.238, проверка имени/подписи включена. API OpenAI проверяется штатными CA, перенаправления не следуются.
- Сертификат действителен до **09.10.2027 09:14:23 UTC**. До этой даты заменить пару на NL и публичный сертификат в новой сборке. Переезд/IP/routing требуют пересмотра allowlist/сертификата и проверки маршрута из контейнера web.
- Шлюз допускает только Responses, `gpt-6-luna`, `store:false`, `service_tier:default`, reasoning none, JSON, максимум1800 выходных токенов. Нет tools/streaming/произвольного upstream, тела запросов до64KiB и ответов до128KiB. Сбой после отправки —502, не доказательство бесплатности. Ни шлюз, ни приложение не повторяют платный запрос автоматически.
- Общий лимит приложения **$10/месяц** и прежние резервы/идемпотентность сохраняются. Для OpenAI верхний тариф входа$0.125/млн включает более дорогую запись кеша; выход$0.50/млн. Стандартный вход$0.10, кеш-попадания дешевле. Это консервативная оценка, не выписка провайдера. Ответ с неожиданным service_tier останавливает генерацию для сверки расходов.

## Настройки и откат

Для этого маршрута используются `AI_TEXT_OPENAI_GATEWAY=true`, `AI_TEXT_GATEWAY_TOKEN`, `AI_TEXT_PROVIDER=openai`, `AI_TEXT_ALLOW_OPENAI=true`, месячный бюджет10. DeepSeek остаётся в коде/секретах, но может быть отключён в выборе через `AI_TEXT_ALLOW_DEEPSEEK=false`. Endpoint/модель не принимаются от браузера. Новых миграций нет.

Выпуск магазина — обычный [регламент](server-staging.md), gateway-переменные включены в основной compose. Сначала развернуть и проверить NL, затем обновить web/worker. Образы до этой доработки не используют gateway: при откате вернуть прежние AI-переменные из точечной приватной копии, иначе старый код пойдёт напрямую к OpenAI из РФ. Прежние файлы env целиком поверх новых ключей не копировать.

Для отключения шлюза: сначала выключить OpenAI в магазине либо вернуть согласованный провайдер, затем `systemctl disable --now autoreelz-ai-gateway` на NL. Amnezia не останавливать. Журнал расходов/результаты и API-ключи не удалять. `/health` шлюза требует секрет; проверять с сервера магазина, не публиковать значение токена в командах/чатах.

## Проверки

`python3 tests/ai-gateway.py` — auth/путь/границы/модель/формат/тариф/один upstream-вызов/неопределённый ответ и отказ редиректов. `tests/ai-text.test.ts` — фиксированный маршрут, отсутствие повтора, тариф и существующие защиты. `check`, `test`, `build` — [правила](testing.md). Транспортная проверка из web: health200, неверный секрет401, неверный JSON400 без вызова OpenAI, недоверенный сертификат отклоняется. Все платные пробы выполняются через существующий manager API и журнал; повторять старые пробные скрипты нельзя. Доказательства — artifacts/ai-gateway; состояние публикации — [status.md](status.md).

Реальный GET модели на NL вернул200; это проверка технической доступности, не изменение [географических условий OpenAI](https://developers.openai.com/api/docs/supported-countries). Тарифы/параметры сверены09.10 по [модели](https://developers.openai.com/api/docs/models/gpt-6-luna) и [прайсу](https://developers.openai.com/api/docs/pricing).
