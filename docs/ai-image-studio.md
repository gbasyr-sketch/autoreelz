# ИИ-инфографика в редакторе товара

Проверено 09.10.2026. ИИ-инфографика опубликована в manager по отдельному поручению владельца «делаем». Это дополнение к существующей студии шаблонов. На сервере магазина работает отдельный image-worker, на NL — защищённый image gateway14447. Локальный платный пилот закрыт, его история сохранена. App SHA и доказательства — [status.md](status.md).

## Модель и формат

Выбрана **OpenAI GPT Image 2.5 Sunburst** (`gpt-image-2.5-sunburst-2026-09-08`), качество `high`, формат PNG, горизонтальный 3:2, 1536×1024. Это более мощная модель редактирования изображений, выбранная по просьбе владельца; она принимает исходные фото и образец стиля через Image Edits API. Руководство OpenAI рекомендует Images API для создания одной картинки по одному запросу и отдельно подчёркивает, что точность текста/композиции не абсолютна. Поэтому до применения результат сравнивается с оригиналом и проверяется владельцем. [Руководство по изображениям](https://developers.openai.com/api/docs/guides/image-generation) · [справочник Image Edits](https://developers.openai.com/api/reference/resources/images/methods/edit) · [цены](https://developers.openai.com/api/docs/pricing).

Генерируется весь слайд: фон, композиция, акценты и заранее проверенные надписи. Фото товара определяют физический вид; образец задаёт только стиль. Серверный промпт просит сохранять форму, пропорции, физический цвет, кнопки и их маркировку, разъёмы, крепления и фактическое число элементов. Для установки, управления и комплектов действуют отдельные ограничения состава. Это снижает риск ошибок, но не обещает абсолютного совпадения.

## Работа владельца

1. В форме товара открыть «ИИ-инфографика» и выбрать до четырёх снимков из галереи или загрузить новые. Отдельно можно загрузить образец оформления.
2. Выбрать слайд: обложка, характеристики, комплектация, установка или управление. Задать пожелания и цвета, затем вручную проверить заголовок, подписи, примечание и факты.
3. До запуска посмотреть оценку стоимости и утверждённый текст запроса. Рабочий режим сообщает, что фото и текст передаются OpenAI; simulation отдельно указывает, что внешний вызов не выполняется. Подтверждение запускает одно платное задание. Кнопка «Переделать» и каждый новый вариант — отдельные платные действия.
4. Сравнить оригинал и результат. Проверить физический товар, надписи, цвет и состав. Проверенный cover можно закрепить как стиль следующих слайдов.
5. Скачать PNG или выбрать результаты и добавить их в несохранённую форму товара. После этого отдельно сохранить черновик. Генерация/применение не публикует товар и не меняет цену, SKU или остаток.

Применение ИИ-фото добавляет его в общую галерею. Чтобы назначить обложку всем цветам или одному исполнению, нажмите под ним «Сделать главным…» и выберите область применения. Собственные фотографии цветов сохраняются. Затем отдельно сохраните черновик или опубликуйте товар; [подробности](product-editor-proposal.md#главное-фото-и-фотографии-исполнений).

Закрытие окна не отменяет задание. История хранит параметры и версии. Исходники и результаты добавляются новыми файлами; существующие изображения не перезаписываются. Приватные файлы выдаются только пользователю с правами manager и до публикации не доступны покупателям.

## Серверная схема

- API: `POST /api/manager/ai-images` (quote, queue, review, cancel, apply), `GET /api/manager/ai-images` (история) и `POST/GET /api/manager/ai-image-file` (private assets). Запросы используют обычные manager-права, Origin, CSRF и `no-store`.
- `migrations/021_ai_image_studio.sql` добавляет отдельные неизменяемые снимки исходников и историю заданий. После QA миграция021 применена на сервере под транзакцией/advisory-lock и с предварительным DB-only backup. Все применённые миграции001–021 неизменяемы.
- Отдельный `image-worker` выполняет одно задание; Compose даёт210с для завершения текущего запроса при остановке. Унаследованная HTTP-healthcheck выключена: worker не поднимает HTTP-сервер. Он хранит PNG/WebP и долговечную квитанцию в `AI_IMAGE_STORAGE_PATH`. Повтор после перезапуска сначала восстанавливает квитанцию. Задание со спорным сетевым исходом помечается `uncertain` и автоматически не отправляется повторно.
- У каждого запроса есть idempotency key и подпись к проверенной смете/плану. Двойной клик или retry с теми же данными возвращает существующее задание. Изменённые данные требуют нового подтверждения.
- Бюджет изображений находится в отдельных `ar_ai_image_jobs`/`AI_IMAGE_BUDGET_KEY`; месячный текстовый бюджет $10 и его журнал остаются отдельно и не изменяются. Один запрос резервирует $0.50; в коде установлен технический верхний предел пилотного лимита $5.00. Значение окружения по умолчанию `$0`, `AI_IMAGE_PROVIDER=disabled`.
- На сервере worker отправляет запрос через TLS `https://89.124.96.238:14447/v1/images/edits`; прямой OpenAI transport доступен только `local-test`. Gateway требует отдельный токен, разрешает IP сервера магазина/loopback, фиксирует модель/параметры и не журналирует изображения или ключи. `AI_IMAGE_OPENAI_API_KEY` передаётся только worker; web получает лишь `AI_IMAGE_API_KEY_CONFIGURED`. Текстовый `OPENAI_API_KEY` не включает image-функцию и не используется image-адаптером. Активный unit `autoreelz-ai-image-gateway.service`: код `/opt/autoreelz-ai-gateway/images/`, env `/etc/autoreelz-ai-gateway/images.env`, лимиты256MiB/25%CPU/16tasks. Текстовый сервис и Amnezia сохранены.

Картинки нормализуются и проверяются на сервере до сохранения; результат принимается только как PNG1536×1024. PNG остаётся для скачивания, оптимизированный WebP используется для предпросмотра. Существующая галерея товара ограничена прежним лимитом; результат добавляется в форму как новое фото.

## Стоимость и согласование

В официальном калькуляторе OpenAI для Sunburst `high`,1536×1024 отображался расход1372 выходных токена — около **$0.04116 за выходную часть одной картинки**. К этому добавляется тарификация исходных изображений и текста; поэтому это не полная цена запроса. Интерфейс показывает собственную оценку до запуска и фиксированный резерв$0.50. Фактическая сумма по завершении берётся из usage провайдера; если usage отсутствует или расход не сходится, резерв сохраняется и новые платные задания блокируются до сверки. Тарифы и формулу необходимо повторно проверить перед запуском пилота.

В предыдущем локальном пилоте в журнале зафиксировано восемь успешных Sunburst-заданий общей стоимостью **$0.588502**; одно задание стоило$0.064889–$0.086266. Шесть базовых картинок серии (обложка и пять следующих слайдов) составили$0.416145; две правки обложки — ещё$0.172357. Это наблюдение на небольшом наборе фото, не гарантированная цена будущих запросов. Старые расходы хранятся в постоянной локальной пилотной БД и не переносились в рабочую БД сайта.

09.10 владелец ответом «согласовываю» утвердил **дополнительный лимит $5.00** на локальный платный пилот. Это разрешение не включает серверное размещение или публикацию. Согласованный суммарный потолок с предыдущими$0.588502 —$5.588502. Во время пробы оставлен более строгий прежний runtime-лимит$5 на всю пилотную БД; журнал и бюджетный ключ не сбрасывались. Резерв$0.50 — проверка денежного остатка перед вызовом, а не отдельная оплата и не количественная квота.

## Проверки и воспроизведение

- `npm run check`, `npm test`, `npm run build` — типы, общий набор быстрых тестов и production-сборка.
- `node tests/ai-image-database.mjs` — создаёт отдельную `ar_qa_ai_images_*` базу, гоняет только simulation/fake adapter и удаляет QA-базу. Внешних вызовов нет.
- `python3 tests/ai-image-gateway.py` — проверяет фиксированную модель/маршрут, границы тела и multipart-преобразование без обращения к OpenAI.
- Для HTTP-проверок запустить сборку с `tests/helpers/ai-image-preview.mjs` на уникальной QA-БД и временном каталоге, указав `AI_IMAGE_PROVIDER=simulation`; затем `node tests/ai-image-api.mjs`. Скрипт `tests/ai-image-studio-browser.mjs` проверяет реальный manager UI через Playwright на1440/375px с тем же simulation-провайдером. Использовать новый `AR_IMAGE_PREVIEW_DATABASE`, каталог `AR_IMAGE_PREVIEW_DIR` и отдельный `AR_AI_IMAGE_ARTIFACT_DIR`, затем удалить только эту QA-БД и временные файлы.
- `tests/ai-image-pilot.mjs` — платный инструмент: **не запускать без отдельного согласованного лимита**. Изменение `AR_AI_IMAGE_PAID_PILOT`/переменных провайдера само по себе не является разрешением на расходы.

В первоначальной локальной проверке Chrome/Docker были недоступны: интерфейс проверялся в браузере Codex, API/DB с simulation и `externalCalls:0`. При выпуске server build/Compose/Caddy выполнены на сервере; опубликованный UI проверен на1440/375 через установленный Yandex/Chromium с временными профилями. Исходная студия шаблонов также открывается; в публичной проверке карточки не сохранялись.
