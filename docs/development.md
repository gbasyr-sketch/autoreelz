# Локальная витрина — этап 2

Сайт: http://127.0.0.1:14322/. Это выбранное направление A в Astro SSR, без CMS/БД и реальных операций. Архив сравнения прототипов отдельно на 14321.

## Запуск

Нужны Node 24.21.0 и npm 11.19.1. В текущей рабочей папке Node установлен локально, глобальные настройки не менялись:

```sh
export PATH="$PWD/.tools/node-v24.21.0-darwin-arm64/bin:$PATH"
node --version
node /opt/homebrew/lib/node_modules/npm/bin/npm-cli.js run dev
```

На другом компьютере установите ту же версию Node из официального дистрибутива (либо своим менеджером версий, файл .node-version). Используйте npm 11.19.1, затем `npm ci` и `npm run dev`. Каталог .tools не переносится через Git. Перед запуском убедитесь, что 14322 свободен либо уже обслуживает эту витрину; существующие чужие процессы не останавливать.

Для проверки сборки:

```sh
npm run check
npm test
npm run build
HOST=127.0.0.1 PORT=14322 node dist/server/entry.mjs
```

В этой сессии браузерные проверки выполнялись по собранному standalone-серверу. Для изменения файлов используйте dev-сервер; после изменения production-сборки её процесс нужно перезапустить.

## Где что находится

- design-system/MASTER.md — утверждённое направление A.
- src/layouts, components, styles — общая оболочка и компоненты.
- src/pages/index.astro, catalog.astro, product/[slug].astro — основные страницы.
- src/lib/demo.ts — 8 явно демонстрационных товаров, SKU и фиксированные составы. UUID и артикулы DEMO относятся только к fixtures, не заменяют реальные артикулы владельца.
- src/lib/catalog.ts — серверная фильтрация по одному SKU, поиск/сортировка, входные ошибки и неизвестная совместимость.
- src/scripts — небольшие клиентские улучшения без React. Поиск, фильтры и URL вариантов работают без JS.
- public — локальные шрифты с OFL, оригинальные SVG-экспорты логотипа и подписанные иллюстрации-заглушки.
- artifacts/stage-2 — снимки экрана и результаты браузерных проверок.

Избранное и демонстрационная корзина сохраняются только в текущем браузере. Они не являются заказами и не резервируют остатки. Их можно очистить кнопкой в корзине либо удалением ключей autoreelz-new-demo-* в хранилище браузера. Отсутствие/ошибка хранилища показывает сообщение пользователю.

## Сценарии для просмотра

- `/catalog?category=heaters&illumination=blue&max=5200` — выбранное исполнение в выдаче.
- `/catalog?category=heaters&illumination=white&availability=in-stock` — пустой фильтр.
- `/catalog?q=несуществующая` — пустой поиск.
- `/catalog?min=9000&max=100` — ошибка цены с исправлением формы.
- `/catalog?vehicle=priora-2&year=2015&ac=yes` — неизвестная совместимость.
- `/product/heater-control?sku=00000000-0000-4000-8000-000000001003` — белая подсветка, предзаказ, правильные данные уже в SSR HTML.
- `/product/interior-kit` — фиксированный комплект, без переключателей исполнений.
- `/product/multimedia-kit` — весь комплект в предзаказе.
- `/product/heater-control?sku=foreign` — 404 для неизвестного исполнения.
