# Серверная проба удаления фона

Дата: 30.09.2026. Два исходных JPEG, переданных владельцем. Нормализация длинной стороны до1600px; веса/контрольные суммы совпадают с локальным пилотом.

Изолированный rootless Docker пользователя autoreelz2026. Один CPU, один поток ONNX, pids64, read-only rootfs, без сети, без capabilities, no-new-privileges. Только собственные mounts inputs/models (ro) и results (rw); доступа к БД, env и uploads магазина нет. Сначала лимит2GiB безswap; после явных поручений владельца —3.5GiB (3584MiB) безswap и3CPU/3потока. Лимиты проверены чтением cgroup и docker inspect.

Python3.12-slim base digest: sha256:f77ac9e44ae96ef2c90b8053ea08c31f8be030f824196b0ae4db6d462c84e51f. Прямые зависимости закреплены в scripts/background-removal-requirements.txt. Контрольная сумма модели проверяется до сессии. Обработка не обращается к внешним API.

Монитор проверяет origin /health примерно каждые4с и останавливает только тестовый контейнер после двух ошибок/ответов дольше3с либо300с общего времени. Образ/контейнеры магазина эта проба не меняет. RSS — пик всего процесса, включая построение сравнения и сохранение PNG, не только инференс. Время инференса исключает загрузку модели, чтение исходника и запись PNG; полное время двух фото — StartedAt/FinishedAt в monitor.

Во время подготовки параллельно изменился релиз магазина (b112d64 →9f09752 →fa7a625), поэтому это не контролируемое сравнение задержек до/после. Все наблюдавшиеся ответы /health сохранены; успешная малая проба не является полной нагрузочной аттестацией.
