# AUTO REELZ — визуальные прототипы

Запуск из корня репозитория:

```sh
python3 prototypes/serve.py
```

Открыть http://127.0.0.1:14321/. Если порт занят, сначала выяснить, не работает ли уже этот preview; чужие процессы не останавливать.

- index.html — сравнение направлений.
- a.html / a-product.html — Светлая витрина.
- b.html / b-product.html — Техно.
- screenshots — снимки браузера, не фотографии товаров.

Статические прототипы без внешних API и записи данных. Избранное и корзина — временная демонстрация, сбрасываются при переходе. Сервер слушает только localhost, отправляет noindex и no-store.

Дизайн и результаты проверки: [design-directions.md](../docs/design-directions.md).
